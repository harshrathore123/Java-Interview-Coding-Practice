# Java Interview Coding Practice 🚀

A structured Java repository for **Coding / DSA interview preparation**.

This repository contains Java coding problems, solutions, common DSA patterns, optimization practice, and interview-oriented problem solving.

The main goal is to practice:

- Writing correct Java solutions
- Understanding different approaches
- Improving time and space complexity
- Identifying optimization patterns
- Performing dry runs
- Handling edge cases
- Explaining solutions clearly in interviews

---

## 📚 Repository Structure

This repository is organized using **Git branches**, where each branch represents a different topic or practice category.

### Main Branches

- `array-basic` → Basic Array problems
- `array-advanced` → Advanced / Intermediate Array problems
- `strings` → String coding problems
- `searching` → Searching and Binary Search problems
- `sorting` → Sorting algorithms and problems
- `hashing` → HashMap / HashSet problems and patterns
- `stack` → Stack problems
- `queue` → Queue problems
- `linked-list` → Linked List problems
- `recursion` → Basic Recursion problems
- `two-pointers` → Two Pointer pattern problems
- `sliding-window` → Sliding Window problems
- `genesis` → General / Mixed Coding Practice

---

## 🎯 Interview Preparation Focus

For every coding problem, the target is to practice:

1. Understand the problem
2. Build a brute-force solution
3. Check correctness with test cases
4. Understand Time Complexity
5. Understand Space Complexity
6. Identify the optimization pattern
7. Build an optimized solution
8. Perform a dry run
9. Check edge cases
10. Explain the approach clearly
